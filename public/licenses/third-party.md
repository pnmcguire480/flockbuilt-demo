# Third-party components

The portable demo includes self-hosted font files and browser JavaScript bundled from GSAP and Lenis. Font SIL Open Font License and Lenis MIT license texts are included in `dist/licenses/`. GSAP attribution and its standard-license reference are preserved in the bundled code and README copy in that folder. Astro is used to build the static pages; Node.js is the existing local runtime.

Source dependencies and exact versions are recorded in `package-lock.json`. The reference photographs are client material from the original project; public-use approval remains part of the client fill-in list.
